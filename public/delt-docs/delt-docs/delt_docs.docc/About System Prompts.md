# About System Prompts

The source of truth for agent template system prompts.

## About System Prompts

There are technically four templates for every agent rank. The ranks are:

1. Chief
2. Director
3. Supervisor
4. Attendant
5. Senior Analyst
6. Junior Analyst

### Teaming

Each agent is randomly assigned a "team". The teams are the four suits of a standard deck of cards:

- Hearts (red)
- Diamonds (red)
- Clubs (black)
- Spades (black)

### Organization

This folder contains one file for each rank. This prompt is then combined with the agent's team prompt to create the final system prompt for the agent.
